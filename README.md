### Areas of Interest

- **Data Engineering:** Batch ingestion, data quality, dimensional modeling, orchestration, and query performance.
- **Data Science:** Exploratory analysis, statistical reasoning, and communicating findings through dashboards.
- **Machine Learning:** Risk modeling, model evaluation, and explainable predictions.
- **Applied AI:** Retrieval systems, document processing, and speech applications, with clear attention to what is implemented and validated.
